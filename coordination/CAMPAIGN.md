# Six-track campaign

The tracks are deliberately orthogonal.

| Track | Mission | Success condition |
|---|---|---|
| A | Exact CARD9 / finite certificate | CARD9 exact infeasibility certificate, or a genuine phase-feasible 9-packet |
| B | Structural slab/concentration theorem | Symbolic lemma explaining/rejecting near-extremal `a0=0,a1=2` concentration |
| C | Common-U / triangle / blocker packet attack | Direct contradiction or reduction for a small surviving packet, especially repeated-power 0x7f geometry |
| D | HN / BBMST analytic bridge | Rigorous correlated survivor-dispersion inequality preserving repeated powers |
| E | Adversarial referee | Reproduce/falsify A–D and maintain dependency ledger |
| F | Global lift + 13–73/>73 interface | Prove/audit what would remain after state 2275 closes |

The coordinator should merge only independently checkable results. A–D may proceed in parallel. E should inspect them continually. F should work ahead so a hidden global interface does not invalidate a local victory.
