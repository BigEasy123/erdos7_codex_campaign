# PASSED — Audited and Approved

Theorems that have passed **E_referee** independent audit and falsification.

These records are **locked** and their theorems:
- Status is upgraded from `CANDIDATE_EXACT`/`CANDIDATE_SYMBOLIC` to `PROVED_EXACT`/`PROVED_SYMBOLIC`.
- Can now be used as dependencies for closing QED-gate edges.
- Audit log (Section 7) contains full reviewer sign-off.

Once a theorem is PASSED, if a later falsification or error is found, it moves back to `../FAILED/` and dependent gates must be re-opened.

Historical reference: All approved theorems indexed in `../README.md`.
