# Referee master audit

## Executive verdict

The project is not yet in a proved state. The strongest exact local artifacts are the replayable exact low-prime finite certificates already stored in artifacts/exact, but the current block is the exact phase-cardinality bridge and the global arbitrary-depth interface.

The referee conclusion is:

- exact low-prime finite witnesses are valid and replayable;
- the common-U 284-case theorem is a genuine local exact theorem with finite replay;
- the CARD9 phase model is not an exact theorem object because the children and Hunter rows are still float-generated and not independently rationalized;
- no exact finite proof of CARD9 closure, no exact phase dual, and no exact global lift has been produced.

This is a failure of the proof chain, not a failure of the exact checkers.

## A. Least-counterexample logic

### Verdict: PLAUSIBLE_UNAUDITED

The repository contains the right least-counterexample vocabulary, but no exact finite proof that the compression and reduction steps preserve the full problem class under the project’s own hypotheses.

The main issues are:

- compression steps are not independently replayed as exact finite proofs;
- oddness and distinctness preservation are only assumed in the local calculus, not proven in a closed statement;
- no exact ledger shows that every secondary-minimization step is valid on the full canonical family.

This remains a legitimate proof obligation, not a counted theorem.

## B. p-adic frame logic

### Verdict: NUMERICAL_ONLY

The repository contains strong structural checkpoints and exact local proofs for the low-prime part, but the final p-adic frame / blocker derivation is not available as a closed exact certificate.

The exact local certificates in artifacts/exact show the finite low-prime execution path is sound, but they do not validate the arbitrary-depth repeated-power framework that would be needed for a final theorem.

## C. Common-U semantics

### Verdict: AUDITED_EXACT

The exact common-U theorem is the strongest exact local theorem currently in the repo. The checked artifacts show exact finite replay for the 284-case common-U target family and exact Farkas certificate replay.

This theorem proves a precise local obstruction only within its stated exact finite model. It does not prove arbitrary-depth closure by itself.

## D. Repeated powers

### Verdict: BROKEN

The project still treats repeated powers too casually. The exact literature and code structure repeatedly distinguish squarefree and repeated-power behavior, but the final arbitrary-depth bridge is still formally missing.

This is not just a coding issue: the project cannot claim to have closed the repeated-power problem until it proves that the structural conditions used for squarefree supports remain valid when powers are repeated.

## E. Hunter cuts

### Verdict: AUDITED_EXACT at the source-provenance level

The exact source reconstruction was verified: the exact heavy-vector weights and the Hunter cut log can be replayed as exact source objects without the float matrix. This is genuine progress and is more convincing than the earlier float-only claim.

However, this is not a full proof of the global Hunter system. It is a valid exact provenance result for the source families and the stored cut log, not a theorem about full cardinality-9 emptiness.

## F. Child pooling

### Verdict: BROKEN

The current numerical model contains float casts in unresolved-group and child-capacity rows, which means the numerical build is not an exact theorem model.

The exact source reconstruction identifies the problematic float conversion points and proves the exact upstream values are available. But the actual child-pooled exact model remains not fully serialized and not independently verified as a theorem object.

This is a genuine proof-engineering gap, not a minor issue.

## G. HN / BBMST interface

### Verdict: PLAUSIBLE_UNAUDITED

The repository contains the right concepts and exact coefficient sources, but the interface between the local low-prime residual and the published high-prime theory is still not established as a theorem in our notation.

The low-prime state has strong exact local certificates, but the jump to the analyzed repeated-power high-prime handoff must still be written and audited.

## H. 7,637-state lift

### Verdict: OPEN

There is no exact or symbolic theorem in the repository proving that local state-2275 extremality dominates all 7,637 canonical states. The project treats this as a likely route, but it is not yet a proven dependency.

## I. Exact certificate chain

### Verdict: SEMI-AUDITED, still broken at the phase layer

The exact replay path for the local finite low-prime artifacts is valid. But the exact phase-cardinality certificate chain is not complete:

- no exact optimizer-free dual certificate for a saved rejected 9-parent set was produced;
- no exact finite UNSAT object for the CARD9 problem was emitted;
- exact matrix serialization and inspection remain incomplete.

## Concrete findings

1. The exact finite low-prime and common-U artifacts are a real proof resource, not noise.
2. The exact CARD9 bridge is still not valid as a theorem object.
3. The float matrix is not a proof artifact; it is a numerical model.
4. The arbitrary-depth / repeated-power interface is the dominant unclosed gate.
5. No final QED claim can be maintained by the current repository state.

## Referee recommendation

The project should keep the exact common-U and replayable low-prime artifacts, but it must stop treating the CARD9 phase model as a theorem. The real next objective is to produce one exact dual certificate on a specific rejected 9-set, then scale only after a valid exact replay chain has been demonstrated.
