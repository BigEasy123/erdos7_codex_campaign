# Repeated-Power Descent Theorem

Status: **OPEN**

The desired theorem is that every maximally branched repeated-power terminal configuration of normalized types 85--90 either strictly descends in the least-counterexample ordering, forces new prime support, or is killed by an exact CRT/common-U contradiction.

The finite classification currently enumerates all 90 normalized order types and identifies 23 squarefree types. That classification is not a descent proof. In particular, the repeated-power types still require explicit preservation checks for covering, oddness, distinctness, and strict decrease under q-frame, hub, blocker, pivot, or exponent-rectangle operations.

No repeated-power type 85--90 is promoted as closed, and no arbitrary-depth gate is closed by this document.
