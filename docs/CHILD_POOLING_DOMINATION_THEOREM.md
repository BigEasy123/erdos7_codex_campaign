# Child-pooling domination theorem

## Status

OPEN

## Goal

Establish that for every legitimate arbitrary-depth continuation, the exact child-pooled relaxation contains the true feasible set:

```text
true feasible set ⊆ relaxation feasible set
```

## Current evidence

The exact family reconstruction confirms that the upstream coefficient families are rational and recoverable, but the actual exact child-pooling model still remains blocked by coefficient provenance and exact dual verification. The repository also does not yet provide a symbolic proof that every genuine continuation maps to a feasible point of the exact pooled relaxation.

## Required subcases to check

1. classes with no further 3-power;
2. resolved deep-3 classes;
3. unresolved deep-3 classes;
4. tails containing 3;
5. tails not containing 3;
6. repeated powers of 5, 7, 11;
7. shared next-digit allocation.

## Conclusion

The theorem is not proved. The model remains a candidate relaxation and must not be promoted as exact theorem-ready until this domination result is established and replayed.
